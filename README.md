# agrinho# 🌱 Agrinho 2026 - Agro Forte, Futuro Sustentável

Site educativo desenvolvido para o **Agrinho 2026**, com o tema **"Agro Forte, Futuro Sustentável: Equilíbrio entre Produção e Meio Ambiente"**.

---

## 🎯 Sobre o Projeto

Este site foi criado para ajudar estudantes a entenderem a importância do equilíbrio entre a produção agrícola forte e a preservação do meio ambiente.

**Tema Oficial:**  
**Agro Forte, Futuro Sustentável**

---

## ✨ Funcionalidades

- Design moderno, clean e responsivo
- Totalmente em português
- Navegação fluida com menu fixo
- Seções interativas
- Imagens de alta qualidade (via Unsplash)
- CSS separado para melhor organização
- Fácil de editar e personalizar
